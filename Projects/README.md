HOW TO USE THIS PROGRAM
clone this repo using 'git clone' > the green button written 'code'

After cloning the repo, navigate to the Projects folder and compile the file-obfuscator with 
gcc file-obfuscator.c -o fileobfuscator

<!-- I don't know the commands in apple or windows. You can find out by simply googling or youtubing around>

To obfuscate a file, run the command below

./file-obfuscator <write your key here but remove these angled brackets> < write the name of the file you want to encrypt > write the name of the file output for the encrypted file

EXAMPLE:
./file-obfuscator mykey < secret > encrypted_secret_File
